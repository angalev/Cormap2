# CLAUDE.md

Проект и вся переписка по нему — на русском. Комментарии в коде и сообщения
коммитов пишутся по-русски.

## Что это

Веб-сервис построения коррозионных карт (приложение № 11 технического отчёта по
коррозионному обследованию). Пользователь входит под своей учётной записью,
загружает книгу Excel и получает карту: PDF, PNG и Excel с графиками.

Полное задание — в `TZ.md`. Читать его перед любой работой. Решения по умолчанию
на открытые вопросы — в разделе 14 `TZ.md`, отложенные задачи — в разделе 13; если ответ заказчика меняет решение,
сначала правится `TZ.md`, потом код.

## Откуда брать сведения

- `reference/template.xlsx` — входной шаблон версии 1 (15 колонок). Версия 2
  описана в `TZ.md`, раздел 4.1.
- `reference/test_data.xlsx` — пример входных данных: на листе `Template` 5 точек,
  лист `Result` показывает вид настоящих данных (тысячи строк с шагом 2 м).
- `reference/prilozhenie_11_obrazec.docx`, `reference/obrazec_list1.png`,
  `reference/obrazec_list2.png` — эталон внешнего вида двух листов карты.
- `reference/legend/` — картинки условных обозначений из образца. Они мелкие
  (11–70 px) и служат только образцом для перерисовки в SVG.
- Исходная система АКФОД — справочник, не источник кода. Если её репозиторий
  лежит рядом (`../acfod`), смотреть ветку `main`: генератор карты
  и класс отрисовки схемы трассы. Код оттуда в этот
  проект не копируется: он чужой и написан под Django 1.9 и Python 3.6.

## Правила

- Ядро `cormap/` не импортирует Django и работает из командной строки.
- При отрисовке длинных линий прореживание сохраняет минимумы и максимумы.
- Колонки книги ищутся по тексту заголовка, не по букве.
- Критерии повреждений ИП живут в файле настроек, не в коде. Пока заказчик их
  не передал, расчёт выключен; придумывать критерии самостоятельно нельзя.
- Нераспознанная пометка в «Комментарии» всегда попадает в отчёт проверки.
- Каждая страница сайта и каждый файл доступны только после входа; чужие карты
  пользователю не видны. На это пишется тест.
- Работа идёт по этапам из раздела 13 `TZ.md`, по одному. Этапы 1–7 делаются без
  сайта. Каждый этап заканчивается тестами и сверкой с образцом.
