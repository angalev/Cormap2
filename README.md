# cormap — коррозионные карты

Веб-сервис и библиотека для построения коррозионных карт подземного трубопровода
(приложение № 11 технического отчёта по коррозионному обследованию). Пользователь
входит под своей учётной записью, загружает книгу Excel с замерами и получает
карту: PDF, PNG и книгу Excel с графиками.

Полное техническое задание — в [`TZ.md`](TZ.md).

## Быстрый старт — сайт

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev,web]"
run_local.bat
```

Поднимает сайт на `http://127.0.0.1:8000/` и обработчик заданий в отдельном
окне, накатывает миграции и создаёт демо-пользователей (только в этом,
локальном режиме — `CORMAP_DEBUG=1` ставит сам `run_local.bat`):

| Логин | Пароль | Права |
|---|---|---|
| `admin` | `Karta-2026-test` | суперпользователь, админка Django |
| `ivanov`, `petrov` | `Karta-2026-test` | обычные пользователи |

Загрузите `reference/test_data.xlsx` на странице «Новая карта» — это
синтетические данные, собственного файла не нужно. Остановка: Ctrl+C в окне
сайта и закрыть окно обработчика.

## Возможности

- Чтение книги Excel: колонки ищутся по тексту заголовка, а не по букве; отчёт
  проверки показывает каждую нераспознанную пометку.
- Карта на два листа для каждого участка трассы: графики (потенциал, градиенты,
  УЭС, глубина заложения) и полоса «Объекты на трассе» с условными обозначениями.
- Автоматическое и ручное разбиение трассы на листы; трассы до 300 км.
- Прореживание длинных линий при отрисовке сохраняет минимумы и максимумы.
- Значки и текстуры грунтов и изоляции в SVG и PNG.
- Расчёт коррозионного прогноза.
- Сайт на Django: вход по учётной записи, очередь заданий, журнал действий,
  ограничение попыток входа, изоляция карт разных пользователей.
- Развёртывание на Ubuntu: nginx, gunicorn, PostgreSQL, резервное копирование
  (каталог `deploy/`).

## Устройство

| Каталог | Назначение |
|---|---|
| `cormap/` | Ядро: чтение, проверка, разбиение, отрисовка PDF/PNG/Excel. Не зависит от Django, работает из командной строки |
| `web/` | Сайт на Django 5.2 и обработчик заданий |
| `deploy/` | Установка на сервер, nginx, systemd, резервные копии |
| `tools/` | Сборка значков, демонстрационных книг, поставки |
| `tests/`, `web/tests/` | Тесты ядра и сайта (pytest) |
| `reference/` | Образец внешнего вида карты и шаблон входной книги |

Стек: Python 3.12, Django 5.2 LTS, PostgreSQL, openpyxl, matplotlib, Pillow,
pytest, ruff.

## Запуск

```bash
python -m venv .venv
.venv/Scripts/pip install -e ".[dev,web]"      # Windows; на Linux: .venv/bin/pip
```

Командная строка (без сайта):

```bash
python -m cormap template шаблон.xlsx                      # пустой шаблон книги
python -m cormap check reference/test_data.xlsx            # проверка книги
python -m cormap build reference/test_data.xlsx --out out --name "Газопровод"
```

Сайт локально (Windows): `run_local.bat` — миграции, сайт и обработчик заданий.
Режим разработки включается переменной `CORMAP_DEBUG=1`; на сервере обязательны
`CORMAP_SECRET_KEY` и адрес базы (см. [`deploy/install.sh`](deploy/install.sh)).

## Тесты

```bash
pytest              # быстрые тесты
pytest -m slow      # трасса 300 км
ruff check .
```

## Что не входит в репозиторий

Модуль предварительной обработки `cormap/refinery.py` принадлежит заказчику и
в репозиторий не кладётся. Интерфейс описан в `TZ.md` (раздел 4.5); в тестах его
заменяет `tests/fake_refinery.py`. Критерии повреждений ИП вынесены в файл
настроек `cormap/assets/settings/defects.toml`.
